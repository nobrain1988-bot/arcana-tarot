1909年のライダー・ウェイト・スミス版78枚すべてを、実際のリーダーが読むとおりに。アカウントも、サブスクも、リーディングの途中で出てくる課金画面もありません。

カードは自分でめくります

カードが切られ、伏せたまま目の前に広がります。選ぶのはあなたです。指が触れるまで何も決まりません — リーダーと向かい合って座るのと同じです。

スプレッドではなく、質問から

タロットが初めての人に「過去・現在・未来」は選びようのない名前です。だからアルカナは、まず何を知りたいかを尋ね、スプレッドはアプリが決めます。カードの位置も質問に合わせます — 「見えていないことは?」と尋ねれば、過去・現在・未来ではなく見えているもの / 隠れているもの / 知るべきことの位置にカードが置かれます。

恋愛

今どんな関係か、相手の気持ち、何が必要か。

片想い・復縁

最初の一歩、途絶えた連絡、手放すこと、残ったもの。

仕事・勉強

何が止めているか、自分の強み、どう転ぶか。

お金・選択

何から解くか、本当に大事なこと。

健康

診断ではなく、心を見つめるための場所です。体のことは医師に相談してください。

今日の一枚

一日のあいだ固定。朝めくって夜もう一度開いても同じカード。

作り話ではなく、計算された読み

多くのタロットアプリは文章を無作為に選びます。アルカナはすべてのリーディングを、実際に出たものから組み立てます — カードと正逆、置かれた位置、大アルカナが何枚か、逆位置が何枚か、四大元素の偏りまで。イエス・ノーの答えも、コイン投げではなく各カードに古くから定まった極性に従います。

はじめから集めない設計

サーバーもログインもありません。今日のカードも、記録も、設定も、この端末の中だけにあります。入力した質問は保存も送信もされません。リーディングに通信はまったく要りません。
